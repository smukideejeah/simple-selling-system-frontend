# Aplicación de gestión de ventas
Frontend de la aplicación de gestión de ventas que se aloja en [este repositorio](https://github.com/smukideejeah/simple-selling-system-backend)

## Tecnologías
- React
- TypeScript
- Ant Design
- Vite

## Requisitos
- Node.js 24.12.2 (probado en esta versión)
- npm o pnpm
- Ant Design
- Vite

## Instalación
```bash
npm ci
npm run dev
```

La app levanta en: `http://localhost:5173`
Configura la variable de entorno: `VITE_API_URL=http://localhost:3000`

## Funcionalidades
- Listado y búsqueda de productos
- Carrito de compras
- Registro de ventas
- Aplicación automática de descuentos
- Gestión de clientes (nombre, apellido, NIT)
- UI con Ant Design (sin CSS artesanal innecesario)
